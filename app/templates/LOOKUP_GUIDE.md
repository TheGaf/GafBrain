# GafBrain Lookup Guide

Use the smallest file that answers the question.

## Chronology
Use `timeline.json`, `timeline-YYYY.json`, `months/YYYY-MM.json`, or `monthly-stats.json`.

## Exact wording
Use `verbatims.json` or the smaller monthly verbatim files.

## Topics, projects, people, themes
Use `search-index.json` and `GAFBRAIN_INDEX.md` as a map.

## Full context
After locating the right record, open the normalized Markdown file listed in its `path` field.

## Rules
- Prefer structured JSON for retrieval.
- Use Markdown for full context.
- Prefer recent explicit decisions when history conflicts.
- Distinguish the user's words from AI suggestions.
- If the evidence is missing, say so instead of guessing.
