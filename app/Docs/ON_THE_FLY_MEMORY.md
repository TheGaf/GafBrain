# On-the-Fly Memory

During a build session, use:

```bash
npm run session:log -- "Decision: app is disposable, Raw is sacred, Brain is reproducible."
```

The note is appended to:

```text
Brain/Sessions/active-session.md
```

At the end of a session, useful durable notes can be copied into Brain files or future compiler outputs.

Raw session notes are working memory, not immutable source material.
