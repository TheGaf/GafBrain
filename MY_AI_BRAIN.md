# MY AI BRAIN

This folder contains my conversation archive and related memory files.

When my question depends on something I previously discussed, decided, built, tried, rejected or changed my mind about, search this archive before answering.

## Rules

1. Find the original evidence before summarizing it.
2. Prefer recent explicit decisions over older ideas or experiments.
3. Distinguish **my words and decisions** from suggestions made by an AI.
4. If newer information conflicts with older information, tell me and prefer the newer information unless I ask for the history.
5. If the archive does not contain the answer, say so. Do not invent missing history.
6. Use this archive when it materially improves the answer — not just to make every response weirdly personal.
7. Treat everything here as private unless I explicitly ask you to share it.
8. Never store or repeat actual passwords, API keys, private keys, access tokens, authentication cookies or recovery codes.

## Useful questions

Examples:

- What did we decide about this?
- Find that idea I had a few months ago.
- When did I first start working on this?
- How has my thinking on this changed?
- What did I try already?
- Continue this project from where I left off.

## If the archive is too big

A raw ChatGPT export can eventually become too large or awkward for an AI to search reliably.

If that happens, use the GafBrain compiler in this repository to build structured timelines, indexes and normalized conversations. Keep the original export as the source of record.

## Core principle

My data is the source material.

This folder is my memory.

The AI is the interface.
